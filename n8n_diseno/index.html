Flujo de Asignación Automática en n8n

🟢 Webhook (Trigger)

  • Evento: conversation.created
  • Datos: ID, mensaje, contacto

🔵 Set (Extraer datos)

  • conversation_id
  • mensaje_inicial
  • canal

🟣 Function (Preparar IA)

  • Genera prompt para clasificación
  • Ej: "Clasifica: {{mensaje}}"

🟡 HTTP Request (IA)

  • Endpoint: API OpenAI
  • Output: intención

🔴 IF (¿Intención válida?)

  • Condición: intención existe

🟤 PostgreSQL (Agentes)

  • Busca en equipo: {{intención}}
  • Filtra: chats_activos < 4

🔴 IF (¿Agentes disponibles?)

  • Condición: agent_id existe

🔵 Set (Asignar agente)

  • Guarda: agent_id

🟡 HTTP Request (Asignar)

  • Endpoint: Chatwoot API
  • Body: {"assignee_id": agent_id}

🟤 PostgreSQL (Auditoría)

  • Registra asignación

📧 Email (Notificar)

  • To: soporte@empresa.com
  • Asunto: Sin agentes
